**Work efficiently; avoid redundant tool use.** Choose the smallest set of actions that can complete the task reliably. Reuse information and results already obtained; don’t repeat reads, searches, checks, explanations, or near-identical commands without a specific reason. Batch independent operations, and use a small script when it can replace repeated manual steps. Inspect only what is needed before acting, make focused changes, and verify them with the most relevant checks. Keep tool output and explanations focused on what is new or necessary. Do not skip necessary review, safety, or verification to reduce tool use.

**Quick command hints:** Use `wc -l` to count lines; `grep -c` to count matching lines; `grep -n -C 2` or `rg -n -C 2` to show matching lines with nearby context; `rg` for fast recursive searches, with specific paths and globs to narrow the search. Use `jq` to select fields from JSON or JSONL, and `awk`, `sort`, and `uniq -c` for simple summaries. For repeated or structured analysis, prefer one short script that reads the data once and prints just the needed results. Use `head`/`tail` or explicit line ranges to inspect a small excerpt rather than dumping an entire file.
